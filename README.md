PhishTrainer 🐈‍⬛🔒

PhishTrainer is an interactive cybersecurity awareness training application that helps users learn how to identify phishing emails through a realistic email inbox simulation.

Live Demo 👉 https://ai.studio/apps/0378a04e-c862-4974-adad-056727b2075b

Features:
Outlook-inspired inbox experience
Easy, Medium, and Hard difficulties
10 realistic email scenarios per session
Real vs Fake classification
Educational phishing explanations
Final score and cybersecurity recommendations
Vader, the cybersecurity guide cat

How It Works:
Choose a difficulty.
Open the unread email.
Decide whether the email is Real or Fake.
Receive educational feedback from Vader.
Complete all 10 emails.
Receive a final score and personalized recommendations.

Tech Stack:
React
TypeScript
Vite
Tailwind CSS
Google AI Studio
